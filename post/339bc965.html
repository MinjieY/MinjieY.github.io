Big Data Analysis of LOL Player Types and Victory Conditions

Abstract

This study analyzes the top 100 players from the latest league matches across five regions in League of Legends (LOL). Using the Rriotwatcher API, match data was crawled on December 19, 2022, yielding 9,226 records. Based on the PySpark distributed computing framework, we completed a full data mining pipeline from data crawling, preprocessing, exploratory analysis, feature extraction, clustering modeling, to result visualization.

Using K-Means clustering, veteran players were classified into 6 types (Average Veteran, Team Support, Objective-Focused, All-Rounder, Speed-Runner, Objective-Passive). Logistic regression revealed three key victory factors: first inhibitor, first tower, and rift herald kills.

Keywords: Big Data Analysis; PySpark; K-Means Clustering; Logistic Regression; Player Classification; League of Legends

1. Background

League of Legends (LOL) is a multiplayer online battle arena (MOBA) game developed by Riot Games, first released in late 2009. In standard matches, two teams of five players compete to destroy the opposing team’s Nexus. Teams can pursue various objectives including destroying turrets, slaying epic jungle monsters, getting first blood, and clearing minion waves.

As a 7-year veteran player, this study aims to identify the key factors behind top player victories and classify veteran player types from a game developer’s perspective to enable targeted marketing and in-game services.

2. Experimental Design

2.1 Research Topics

Using the top 100 players’ data from five regional leagues:

  1. Player Clustering: Classify players based on quantifiable features
  2. Victory Condition Analysis: Identify key victory factors from match metrics

After crawling and preliminary processing, bool types were converted to integers and unnecessary columns removed, yielding 9,226 records in matches.csv.

The crawled data is highly complete with zero null values across all columns. Box plot analysis shows:

  • inhibitorKills has outliers at 3-7, which is plausible in 20-60 minute games
  • baronKills has outliers at 3 (19 matches), reasonable given Baron’s 20-min spawn and 7-min respawn

6.1 Key Victory Factors

The top three features have the most significant impact on victory:

  1. First Inhibitor — destroying it spawns super minions, severely weakening enemy defense
  2. First Tower — breaking the first turret signals map control breakthrough
  3. Rift Herald Kills — Herald enables rapid turret pushing, key to early-game tempo

These results are highly consistent with practical game experience for a turret-pushing game.

7. Summary

7.1 Data Mining Pipeline

The complete data mining workflow comprises four stages:

  1. Data Reading: Load data, compute metrics, clarify scale and tasks
  2. Feature Analysis: Single-feature analysis, multivariate statistics, visualization
  3. Data Cleaning & Preprocessing: Missing value imputation, standardization/normalization, feature selection, correlation analysis
  4. Model Building: Feature/label preparation, train-test split, algorithm comparison

7.2 Algorithm Evaluation

K-Means is simple and efficient on ~10K samples with fast convergence. Limitations include sensitivity to initial values and susceptibility to noise/outliers.

Improvements: K-Means++ initialization, bisecting K-Means, Elkan K-Means (triangle inequality optimization).

7.3 Reflections

This experiment completed a full data mining pipeline using Python, Java, and Scala. PySpark was used for EDA, preprocessing, modeling, and visualization. Big data development is broad in scope with complex distributed systems — focused learning on areas of interest is key.

7.4 Extension: Stream Processing

Beyond static analysis, a Maven + Flink + Spark environment was set up for batch and stream word-count processing, exploring dynamic data processing workflows.
